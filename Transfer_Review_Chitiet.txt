8.1. VE RACK (QUAN TRONG)
-----------------------------------------------------------------------
   GHI CHU: Rack KHONG PHAI la 1 bang rieng trong database.
   Rack chi la 1 TRUONG (column) trong bang Location.
   
   Vi du du lieu trong bang Location:
   +------------+--------------+------+----------+
   | LocationID | LocationCode | Rack | Capacity |
   +------------+--------------+------+----------+
   | 1          | A-01-01      | A    | 100      |
   | 2          | A-01-02      | A    | 100      |
   | 3          | B-01-01      | B    | 100      |
   | 4          | B-01-02      | B    | 100      |
   +------------+--------------+------+----------+
   
   -> Lay rack bang cach SELECT DISTINCT Rack FROM Location
   -> Khong co bang Rack rieng, khong co PK cho rack


8.2. VE INVENTORY (QUAN TRONG)
-----------------------------------------------------------------------
   GHI CHU: Inventory la bang trung gian giua Product va Location.
   Moi san pham tai 1 vi tri chi co 1 ban ghi Inventory.
   Unique Index: (ProductID, LocationID)
   
   Vi du:
   +-------------+-----------+------------+----------+
   | InventoryID | ProductID | LocationID | Quantity |
   +-------------+-----------+------------+----------+
   | 1           | 1         | 1          | 50       |
   | 2           | 1         | 2          | 30       |
   | 3           | 2         | 1          | 20       |
   +-------------+-----------+------------+----------+
   
   -> San pham 1 co tong 80 units (50 tai vi tri 1 + 30 tai vi tri 2)
   -> San pham 2 co tong 20 units (tai vi tri 1)
   
   LUU Y: Khi nhap kho, neu Inventory chua ton tai tai vi tri do,
   he thong TU DONG TAO ban ghi Inventory moi.
   Dieu nay co the tao ra Inventory cho nhung vi tri chua tung co hang.


8.3. VE PARTIAL TRANSFER (CHUYEN MOT PHAN)
-----------------------------------------------------------------------
   GHI CHU: He thong ho tro chuyen mot phan (partial).
   
   +-----------+----------------------------------------------------------+
   | Giai doan | Hanh dong partial                                      |
   +-----------+----------------------------------------------------------+
   | Stock-Out | Co the xuat it hon so luong yeu cau                    |
   |           | Status chuyen thanh "Partial" thay vi "In Transit"     |
   |           | Co the xuat tiep sau (multiple stock-out)               |
   +-----------+----------------------------------------------------------+
   | Stock-In  | Co the nhap it hon so luong da xuat                     |
   |           | Status giu nguyen "In Transit"                         |
   |           | Co the nhap tiep sau (multiple stock-in)                |
   |           | Moi lan nhap tao StockInReceipt RIENG                  |
   +-----------+----------------------------------------------------------+
   
   Dieu nay co nghia:
   - 1 TransferRequest co the co NHIEU StockInReceipt
   - StockOutReceipt chi co 1 (vi chi xuat 1 lan)
   - Kiem tra "fully received" bang cach so sanh:
     SUM(StockInDetail.Quantity) >= SUM(StockOutDetail.Quantity)


8.4. VE KIEM TRA TON KHO (STOCK VALIDATION)
-----------------------------------------------------------------------
   GHI CHU: Ton kho duoc kiem tra o 3 thoi diem:
   
   1. KHI TAO TRANSFER (client-side JavaScript):
      - Load ton kho qua AJAX: GetProductStockByLocation
      - Validate so luong <= available tai vi tri nguon
      - Validate so luong <= available space tai vi tri dich
   
   2. KHI TAO TRANSFER (server-side trong CreateCompleteTransferAsync):
      - Validate lai ton kho tai vi tri nguon
      - Validate lai suc chua tai vi tri dich
      - DUNG TRANSACTION de dam bao toan ven
   
   3. KHI XUAT KHO (ProcessTransferStockOutAsync):
      - Validate ton kho tai thoi diem xuat
      - Neu khong du -> throw exception
   
   LUU Y: Khong co optimistic locking (RowVersion).
   Neu 2 nguoi cung 1 luc xuat cung 1 vi tri, co the xay ra race condition.
   -> De xuat: Them RowVersion hoac SELECT FOR UPDATE.


8.5. VE STATUS FLOW (QUY TRINH TRANG THAI)
-----------------------------------------------------------------------
   GHI CHU: Quy trinh trang thai day du:
   
   Pending --> Approved --> In Transit --> Completed
      |            |            |
      v            v            v
   Rejected    Rejected     Partial
                                |
                                v
                           In Transit --> Completed
   
   Dieu kien chuyen trang thai:
   - Pending -> Approved:   Warehouse Manager cua kho nguon phe duyet
   - Pending -> Rejected:   Warehouse Manager cua kho dich tu choi
   - Approved -> In Transit: Kho nguon xuat kho (full)
   - Approved -> Partial:   Kho nguon xuat kho (partial)
   - In Transit -> Completed: Kho dich nhap du so luong
   - In Transit -> In Transit: Kho dich nhap mot phan (tiep tuc)
   
   LUU Y: Trong code Reject co kiem tra "Pending Destination" nhung
   khong thay Status nay duoc set o dau. Co the la code chua hoan thien
   hoac tinh nang chua su dung.

8.8. VE STOCK-OUT RECEIPT (PHIEU XUAT)
-----------------------------------------------------------------------
   GHI CHU: StockOutReceipt duoc lien ket voi TransferRequest qua
   cot TransferID (nullable). Dieu nay co nghia:
   
   - StockOutReceipt co the lien ket voi SalesOrder (qua SalesOrderID)
   - HOAC lien ket voi TransferRequest (qua TransferID)
   - 1 trong 2 se la NULL
   
   -> Khi xuat cho transfer: TransferID != NULL, SalesOrderID = NULL
   -> Khi xuat cho don ban: SalesOrderID != NULL, TransferID = NULL


8.9. VE CAP NHAT INVENTORY KHI NHAP KHO
-----------------------------------------------------------------------
   GHI CHU: Trong ProcessTransferStockInAsync, co logic kiem tra:
   
   var inventory = await _db.Inventories
       .FirstOrDefaultAsync(i => i.ProductId == item.ProductId 
                               && i.LocationId == item.LocationId);
   
   if (inventory == null) {
       // TAO MOI
       inventory = new Inventory {
           ProductId = item.ProductId,
           LocationId = item.LocationId,
           Quantity = item.Quantity,
           LastUpdated = DateTime.Now
       };
       _db.Inventories.Add(inventory);
   } else {
       // CONG THEM
       inventory.Quantity = (inventory.Quantity ?? 0) + item.Quantity;
       inventory.LastUpdated = DateTime.Now;
   }
   
   -> Day la cach xu ly "upsert" (insert or update)
   -> Neu Inventory chua ton tai -> tao moi
   -> Neu Inventory da ton tai -> cong them so luong


8.10. VE SECURITY (BAO MAT)
-----------------------------------------------------------------------
   GHI CHU: He thong su dung role-based authorization:
   
   +---------------------+----------------------------------------------+
   | Role                | Co the lam gi voi Transfer                  |
   +---------------------+----------------------------------------------+
   | Admin               | Xem tat ca                                  |
   | Warehouse Manager   | Tao, phe duyet, tu choi, xuat/nhap kho     |
   | Inventory Staff     | Xem, xu ly xuat/nhap kho                    |
   +---------------------+----------------------------------------------+
   
   LUU Y: Khi phe duyet, kiem tra:
   - Approve: user phai la Manager cua KHO NGUON
   - Reject:  user phai la Manager cua KHO DICH (status=Pending)
             hoac KHO NGUON (status=Pending Destination)
   
   -> Day la quan ly quyen theo tung kho, khong phai toan he thong.


8.11. VE TONG TIEN (TOTAL AMOUNT)
-----------------------------------------------------------------------
   GHI CHU: TotalAmount trong StockOutReceipt va StockInReceipt
   duoc tinh = SUM(Quantity * UnitPrice) cua tung detail.
   
   Tuy nhien, UnitPrice lay tu Product.SellingPrice (gia ban).
   Dieu nay co ve KHONG PHU HOP voi transfer noi bo vi:
   - Transfer la chuyen hang giua cac kho, khong phai ban hang
   - Nen dung CostPrice (gia nhap) thay vi SellingPrice (gia ban)
   
   -> De xuat: Xem lai viec su dung UnitPrice trong transfer.


8.12. VE TRANSACTION (GIAO DICH)
-----------------------------------------------------------------------
   GHI CHU: Chi CreateCompleteTransferAsync su dung database transaction
   (BeginTransactionAsync). Cac phuong thuc khac KHONG dung transaction:
   
   - ProcessTransferStockOutAsync: KHONG co transaction
   - ProcessTransferStockInAsync: KHONG co transaction
   
   -> Neu xay ra loi giua chung (INSERT StockOutReceipt OK nhung
      UPDATE Inventory FAIL), du lieu se bi INCONSISTENT.
   -> De xuat: Them transaction cho cac phuong thuc nay.

3.1. TRANG TAO TRANSFER (Transfer/Create.cshtml)
-----------------------------------------------------------------------

BUOC 1: Chon kho nguon / kho dich
----------------------------------
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Danh sach kho (dropdown)      | BANG Warehouse                           |
   |                               | Service: GetWarehousesAsync()            |
   |                               | Query: _db.Warehouses.ToListAsync()      |
   +-------------------------------+------------------------------------------+
   
   -> Controller Create() (GET):
      ViewBag.Warehouses = await _transferService.GetWarehousesAsync();
      ViewBag.Products = await _transferService.GetProductsAsync();


BUOC 2: Lay san pham co ton trong kho nguon (AJAX)
---------------------------------------------------
   Khi chon kho nguon, JavaScript goi:
   fetch('/Transfer/GetProductsByWarehouse?warehouseId=' + fromWh)
   
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Ten san pham                  | BANG Product (join tu Inventory)         |
   | Ma SKU                        | Tao tu ProductID: "SKU-00001"           |
   | So luong ton                  | BANG Inventory (SUM Quantity)            |
   +-------------------------------+------------------------------------------+
   
   -> Service: GetAvailableProductsByWarehouseAsync(warehouseId)
   
   QUERY CU THE:
   SELECT ProductID, ProductName, SUM(Quantity) as AvailableQuantity
   FROM Inventory
   JOIN Location ON Inventory.LocationID = Location.LocationID
   JOIN Product ON Inventory.ProductID = Product.ProductID
   WHERE Location.WarehouseID = @warehouseId AND Quantity > 0
   GROUP BY ProductID, ProductName
   ORDER BY ProductName


BUOC 3: Lay rack trong kho (AJAX)
----------------------------------
   Khi chon kho, JavaScript goi:
   fetch('/Transfer/GetRacksByWarehouse?warehouseId=' + warehouseId)
   
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Danh sach ten rack (A, B, C)  | BANG Location (DISTINCT Rack)            |
   +-------------------------------+------------------------------------------+
   
   -> Service: GetRacksByWarehouseAsync(warehouseId)
   
   QUERY CU THE:
   SELECT DISTINCT Rack
   FROM Location
   WHERE WarehouseID = @warehouseId AND Rack IS NOT NULL
   ORDER BY Rack
   
   LUU Y: Rack KHONG PHAI bang rieng. Lay DISTINCT tu truong Rack cua bang Location.


BUOC 4: Lay vi tri trong rack (AJAX)
-------------------------------------
   Khi chon rack, JavaScript goi:
   fetch('/Transfer/GetLocationsByRack?warehouseId=' + wh + '&rack=' + rack)
   
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Ma vi tri (LocationCode)      | BANG Location                            |
   | Ten vi tri (LocationName)     | BANG Location                            |
   | Suc chua (Capacity)           | BANG Location                            |
   | Ton kho hien tai (CurrentStock)| BANG Inventory (SUM Quantity)           |
   | Con trong (AvailableSpace)    | Tinh: Capacity - CurrentStock            |
   +-------------------------------+------------------------------------------+
   
   -> Service: GetLocationsByRackWithCapacityAsync(warehouseId, rack)
   
   QUERY CU THE:
   -- Buoc 1: Lay vi tri
   SELECT * FROM Location
   WHERE WarehouseID = @warehouseId AND Rack = @rack
   
   -- Buoc 2: Voi moi vi tri, tinh ton kho
   SELECT SUM(Quantity) FROM Inventory
   WHERE LocationID = @locationId
   
   -- Buoc 3: Tinh AvailableSpace = Capacity - CurrentStock


BUOC 5: Lay ton kho theo vi tri (AJAX)
---------------------------------------
   Khi chon san pham, JavaScript goi:
   fetch('/Transfer/GetProductStockByLocation?warehouseId=' + wh + '&productId=' + pid)
   
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Vi tri (LocationCode)         | BANG Location (join tu Inventory)        |
   | Rack                          | BANG Location.Rack                       |
   | So luong ton (Quantity)       | BANG Inventory.Quantity                  |
   +-------------------------------+------------------------------------------+
   
   -> Service: GetProductStockByLocationAsync(warehouseId, productId)
   
   QUERY CU THE:
   SELECT Location.LocationID, LocationCode, LocationName, Rack, Quantity
   FROM Inventory
   JOIN Location ON Inventory.LocationID = Location.LocationID
   WHERE ProductID = @productId
     AND Location.WarehouseID = @warehouseId
     AND Quantity > 0

3.2. TRANG DANH SACH TRANSFER (Transfer/Index.cshtml)
-----------------------------------------------------------------------

   -> Controller Index():
      isAdmin ? GetAllTransfersAsync() : GetTransfersForWarehouseAsync(warehouseId)
   
   +-------------------------------+------------------------------------------+
   | Du lieu hien thi              | Nguon du lieu                            |
   +-------------------------------+------------------------------------------+
   | Ma transfer (TR-0001)         | TransferRequest.TransferID               |
   | Kho nguon (From)              | TransferRequest.FromWarehouseID          |
   |                               | -> Warehouse.WarehouseName               |
   | Kho dich (To)                 | TransferRequest.ToWarehouseID            |
   |                               | -> Warehouse.WarehouseName               |
   | San pham (Products)           | TransferDetail.ProductID                 |
   |                               | -> Product.ProductName                   |

   |                               | -> User.FullName                         |
   | Ngay tao (Date)               | TransferRequest.RequestedDate            |
   | Trang thai (Status)           | TransferRequest.Status                   |

   QUERY CU THE (GetAllTransfersAsync):
   SELECT t.*, 
          fw.WarehouseName as FromWarehouseName,
          tw.WarehouseName as ToWarehouseName,
          u.FullName as RequestedByName,
          au.FullName as ApprovedByName,
          d.*, p.ProductName
   FROM TransferRequest t
   LEFT JOIN Warehouse fw ON t.FromWarehouseID = fw.WarehouseID
   LEFT JOIN Warehouse tw ON t.ToWarehouseID = tw.WarehouseID
   LEFT JOIN User u ON t.RequestedBy = u.UserID
   LEFT JOIN User au ON t.ApprovedBy = au.UserID
   LEFT JOIN TransferDetail d ON t.TransferID = d.TransferID
   LEFT JOIN Product p ON d.ProductID = p.ProductID
   ORDER BY t.RequestedDate DESC

7.1. Lay san pham co ton trong kho (GetAvailableProductsByWarehouseAsync)
-----------------------------------------------------------------------
   FROM: _db.Inventories
   JOIN: Product, Location
   WHERE: Location.WarehouseId == warehouseId && Quantity > 0
   GROUP BY: ProductId, ProductName
   SELECT: ProductId, ProductName, "SKU-{ProductId}", SUM(Quantity)
   ORDER BY: ProductName


7.2. Lay rack trong kho (GetRacksByWarehouseAsync)
-----------------------------------------------------------------------
   FROM: _db.Locations
   WHERE: WarehouseId == warehouseId && Rack != null
   SELECT DISTINCT: Rack
   ORDER BY: Rack


7.3. Lay vi tri trong rack voi suc chua (GetLocationsByRackWithCapacityAsync)
-----------------------------------------------------------------------
   FROM: _db.Locations
   WHERE: WarehouseId == warehouseId && Rack == rack
   
   VOI MOI LOCATION:
     SUM Inventory.Quantity WHERE LocationId == loc.LocationId
     -> CurrentStock
     -> AvailableSpace = Capacity - CurrentStock


7.4. Lay ton kho theo vi tri (GetProductStockByLocationAsync)
-----------------------------------------------------------------------
   FROM: _db.Inventories
   JOIN: Location
   WHERE: ProductId == productId 
     && Location.WarehouseId == warehouseId 
     && Quantity > 0
   SELECT: LocationId, LocationCode, LocationName, Rack, Quantity
   ORDER BY: Rack, LocationCode


7.5. Kiem tra suc chua vi tri dich (GetLocationCapacityAsync)
-----------------------------------------------------------------------
   FROM: _db.Locations.Find(locationId)
   
   SUM Inventory.Quantity WHERE LocationId == locationId -> CurrentStock
   
   SUM Inventory.Quantity WHERE LocationId == locationId && ProductId == productId
     -> ProductStock (ton kho cua 1 SP tai vi tri)
   
   AvailableSpace = Capacity - CurrentStock


7.6. Tao transfer (CreateCompleteTransferAsync)
-----------------------------------------------------------------------
   VALIDATE 1: Kiem tra kho nguon ton tai
     FROM: _db.Warehouses.Find(FromWarehouseId)
   
   VALIDATE 2: Kiem tra kho dich ton tai
     FROM: _db.Warehouses.Find(ToWarehouseId)
   
   VALIDATE 3: Voi moi san pham, kiem tra ton kho tong
     FROM: _db.Inventories
     JOIN: Location
     WHERE: ProductId == productId && Location.WarehouseId == FromWarehouseId
     SUM: Quantity -> totalAvailable
     COMPARE: totalRequested <= totalAvailable
   
   VALIDATE 4: Voi moi item, kiem tra vi tri nguon
     FROM: _db.Locations
     WHERE: LocationId == FromLocationId && WarehouseId == FromWarehouseId
   
   VALIDATE 5: Voi moi item, kiem tra ton kho tai vi tri nguon
     FROM: _db.Inventories
     WHERE: ProductId == productId && LocationId == FromLocationId
     COMPARE: Quantity >= item.Quantity
   
   VALIDATE 6: Voi moi item, kiem tra vi tri dich
     FROM: _db.Locations
     WHERE: LocationId == ToLocationId && WarehouseId == ToWarehouseId
   
   VALIDATE 7: Voi moi item, kiem tra suc chua vi tri dich
     FROM: _db.Inventories
     WHERE: LocationId == ToLocationId
     SUM: Quantity -> destCurrentStock
     COMPARE: item.Quantity <= (Capacity - destCurrentStock)
   
   INSERT: TransferRequest
   INSERT: TransferDetail[]


7.7. Xu ly xuat kho (ProcessTransferStockOutAsync)
-----------------------------------------------------------------------
   DOC: TransferRequest + TransferDetails
   
   DOC: Inventory (de kiem tra ton kho)
     FROM: _db.Inventories
     JOIN: Location
     WHERE: ProductId == detail.ProductId 
       && LocationId == detail.LocationId 
       && Location.WarehouseId == warehouseId
   
   DOC: StockOutReceipt (neu da ton tai)
     FROM: _db.StockOutReceipts
     WHERE: TransferId == model.TransferId
   
   INSERT/UPDATE: StockOutReceipt
   INSERT: StockOutDetail[]
   UPDATE: Inventory.Quantity -= detail.Quantity
   UPDATE: TransferRequest.Status = "In Transit" | "Partial"
